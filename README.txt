## 🚀 How to Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all project files, including `profile.jpg`, are in the same folder.
4. Open `index.html` in your web browser.
5. Alternatively, install the Live Server extension in VS Code and click **Go Live** to preview the website.
